## 2024-05-18 - SessionTimelineChart O(n) String Parsing Optimization\n**Learning:** React 컴포넌트 내에서 날짜 문자열을 매 렌더링마다 `new Date().getTime()`으로 파싱하는 작업이 `.map()` 및 `.filter()` 루프 안에서 발생할 경우 심각한 메인 스레드 블로킹(O(N * M))을 유발할 수 있음을 확인했습니다. Recharts와 같은 차트 라이브러리 사용 시 이러한 비효율이 렌더링 성능 저하의 주요 원인이 됩니다.\n**Action:** 차트에 전달할 데이터는 항상 `useMemo`를 통해 메모이제이션하고, 비싼 연산(문자열 파싱 등)은 렌더링 루프 외부나 `useMemo` 내부에서 한 번만 수행하여 숫자형 원시값(Primitive) 형태로 하위 함수 및 컴포넌트에 전달해야 합니다.
