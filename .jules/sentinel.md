## 2024-09-28 - [Windows 환경 커맨드 인젝션 취약점 수정]
**Vulnerability:** Node.js에서 Windows 플랫폼의 `cmd.exe`를 `spawn` 함수로 호출할 때 `windowsVerbatimArguments: true`를 사용할 경우, 기본적인 특수 문자 이스케이프가 비활성화되어 커맨드 인젝션 취약점이 발생할 수 있었습니다. 특히, 외부에서 주입된 URL이나 인자를 제대로 검증하고 이스케이프하지 않으면 쉘 메타문자 (`&`, `|`, `;`, `<`, `>`, `(`, `)`, `^`)를 통해 악성 명령어가 실행될 위험이 있었습니다.
**Learning:** `spawn` 함수가 안전하다고 생각하기 쉽지만, `cmd.exe`와 같이 쉘을 직접 실행하고 `windowsVerbatimArguments: true` 옵션을 사용하면 쉘 인터프리터의 특성이 그대로 반영되어 인젝션에 취약해진다는 점을 확인했습니다.
**Prevention:** 향후 유사한 패턴의 코드를 작성할 때는, URL의 경우 엄격한 프로토콜 검증 (`http:`, `https:`)을 수행하고, Windows 환경에서는 쉘 메타문자를 정규표현식 `/([&|;<>^()])/g`을 통해 모두 캐럿(`^`) 문자로 명시적으로 이스케이프해야 합니다.
