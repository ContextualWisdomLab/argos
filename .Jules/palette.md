## 2024-06-12 - [Accessible Collapsible Stats]
**Learning:** Using aria-expanded, aria-controls, and an ID linking the toggle to its content is a required pattern for accessible disclosures. Hiding decorative text toggles (like ▸) with aria-hidden prevents unnecessary screen reader noise.
**Action:** Always semantically link custom collapsible UI sections with aria-controls/aria-expanded and hide visual-only decorative elements from screen readers.
