## 2023-10-27 - [CRITICAL] Remove hardcoded admin password
**Vulnerability:** A hardcoded plaintext password (`ADMIN_PASSWORD`) was stored directly in the `packages/web/src/lib/server/admin-auth.ts` file, creating a critical risk of compromise if source code is exposed. Previous attempts to "secure" this via slow hashing (PBKDF2) were security theater since the secret was still plaintext in code, and actually introduced a Thread Pool Exhaustion DoS vulnerability on the unauthenticated login endpoint.
**Learning:** Never rely on hashing mechanisms to protect secrets that are hardcoded directly in the source code; doing so is security theater and can introduce performance/DoS bottlenecks if CPU-intensive hashes are used during login flows.
**Prevention:** Always remove hardcoded secrets from source code completely and instead supply them via securely managed environment variables mapped through `zod` schema validations (like `EnvSchema`). Ensure CI/CD workflows are updated to pass expected dummy variables during build steps to prevent pipeline failures.
