## 2024-05-18 - [Fix Path Traversal SAST Warnings & Dynamic Urllib Vulnerabilities]
**Vulnerability:** Semgrep detected path traversal vulnerabilities (user input going into `path.join`) in CLI codebase, and a dynamic `urllib.request.urlopen` use in Python probe scripts.
**Learning:** Functions like `path.join` in JS and `urllib.request.urlopen` in Python are inherently unsafe if user-supplied paths/URLs are not sanitized. Although some alerts may be false positives in test files or local scripts, CI security checks (like OSV and Semgrep) will fail the pipeline.
**Prevention:** Always validate and sanitize user inputs before file operations. Use schema checking (e.g., verifying URLs start with `http://` or `https://`) before calling `urllib.request.urlopen`, and ensure dependencies are kept updated via `pnpm up -r` to avoid OSV vulnerabilities.
