## 2024-05-24 - 가상화 리스트(react-window) 내부 렌더 루프 성능 최적화: 날짜 문자열 파싱 오버헤드 제거
**Learning:** `react-window`와 같은 가상화 리스트 렌더링 시, `Row` 렌더 함수 내부에서 고정된 문자열 값(`sessionStartedAt`)을 매번 `new Date().getTime()`으로 파싱하게 되면 스크롤 시마다 `O(visible_items)` 단위로 불필요한 객체 생성 및 파싱 오버헤드가 발생하여 성능을 크게 저하시키는 병목이 됩니다. 특정 이벤트에 종속되지 않은 고정된 참조값은 렌더 루프 외부에서 한 번만 연산하는 것이 중요합니다. 하지만 반대로 아이템 개별 데이터(각 이벤트의 타임스탬프 등)를 가상화 루프 밖(예: 데이터 빌더 내부)으로 끌어올려 일괄 계산하려 하면 O(total_items) 비용이 발생하여 전체 성능 저하를 초래합니다. (메모: 아이템 특정 연산은 Row에 남겨두고 공통 상수를 리프트-업 하는 최적의 균형 유지 필수)
**Action:** 가상화 리스트에서 렌더 루프 안으로 전달되는 공통 설정값이나 문자열 시간 등은 부모 컴포넌트(`EventList`) 레벨에서 `useMemo`를 이용해 원시 타입(숫자 등)으로 변환 후, `Row` 컴포넌트에는 변환된 값을 내려주어 렌더링 시 불필요한 비용 낭비를 차단합니다.
