## 2024-08-06 - Date parsing 성능 최적화
**Learning:** V8 엔진 등 JavaScript 환경에서 ISO 날짜 문자열을 파싱할 때 `new Date(string).getTime()`를 사용하면 매번 새로운 Date 객체가 할당되어 불필요한 메모리 낭비와 성능 저하를 일으킵니다. 성능에 민감한 렌더링 루프나 유틸리티 함수에서는 객체 할당을 피하는 것이 유리합니다.
**Action:** 단순히 타임스탬프 숫자(밀리초)가 필요한 경우에는 `Date.parse(string)`를 사용하여 객체 할당 없이 빠르게 파싱하도록 코드를 작성해야 합니다.
