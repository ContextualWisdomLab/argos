## 2025-07-05 - Use React useId for Aria Controls Linking
**Learning:** Expanding/collapsing sections like ContextSection were toggling aria-expanded properly, but lacked the critical aria-controls linkage to the content container. This makes it difficult for screen reader users to understand what content is being revealed. Also, missing focus-visible styling on custom custom components degrades keyboard usability.
**Action:** Always link expandable regions to their toggle button using React's useId() hook (to avoid collisions) and aria-controls. Additionally, ensure custom interactive elements like buttons have explicit focus-visible utility classes applied, and decorative icons have aria-hidden="true" to reduce noise.
