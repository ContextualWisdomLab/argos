## 2024-07-21 - [ERD 모델링 도구 보안 강화 학습]
**Vulnerability:** ERD 모델에서 테이블, 컬럼, 외래키 명칭에 대한 기본적 검증(snake_case)만 존재하며, 삭제나 변경 같은 고급 기능이 부재. 외부 입력에 대해 강건한 에러 처리도 다소 부족할 수 있음.
**Learning:** DDL 생성을 위해 입력받는 테이블명과 컬럼명에 대해 엄격한 식별자 규칙을 적용하지 않거나 검증이 미흡하면, 향후 복잡한 SQL 인젝션 공격 또는 예기치 않은 데이터베이스 오류를 유발할 수 있음.
**Prevention:** 모든 입력 식별자에 대해 명확한 검증(`assertSnakeCaseIdentifier`)을 거치고, 모델 내 의존성 무결성을 훼손하는 삭제 작업(참조되는 테이블 삭제 방지 등)에 대한 방어 로직을 마련해야 함.

## 2024-07-21 - [ERD 모델링 도구 무결성 강화]
**Vulnerability:** ERD 모델에 삭제 기능이 추가될 경우 참조 무결성 검증 부재 시 데이터 불일치 및 예외 발생 가능성
**Learning:** `removeTable`이나 `removeColumn` 같은 파괴적 동작 시, 항상 테이블 내외의 `foreignKeys` 의존성을 확인하여 참조 중인 객체의 삭제를 방지해야 함
**Prevention:** 삭제 전 의존성 트리 스캔 및 예외를 발생시키는 방어적 삭제 메서드 구현 (`removeTable`, `removeColumn`)
