## 2024-07-16 - React 렌더링 내 문자열 날짜 파싱(new Date / Date.parse) 오버헤드 제거
**Learning:** 리액트 컴포넌트의 O(N) 반복문(`map` 등) 또는 렌더링 패스 내에서 문자열 형태의 타임스탬프를 매번 파싱(`new Date().getTime()` 혹은 `Date.parse()`)하는 작업은 렌더링 비용을 누적시켜 프론트엔드 성능 병목을 초래할 수 있음. 특히 타임라인이나 리스트 아이템이 많은 차트/리스트 컴포넌트(`session-timeline-chart.tsx`, `event-list.tsx`)에서는 그 영향이 큼.
**Action:** O(N) 루프 이전에 타임스탬프들을 한 번만 `Date.parse`를 통해 숫자형으로 일괄 변환(또는 부모 컴포넌트에서 파싱 후 props로 전달)하여 재사용함으로써, 하위 아이템 매핑과 렌더링 중 발생하는 불필요한 날짜 변환 오버헤드를 제거해야 함.
