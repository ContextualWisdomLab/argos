## 2024-08-02 - 이벤트 리스트 렌더링 시 날짜 파싱 최적화
**Learning:** `react-window`와 같은 가상화 리스트의 렌더링 루프 내부에서 `new Date().getTime()`을 사용하여 날짜 문자열을 파싱하는 것은 불필요한 객체 할당을 발생시켜 성능 저하의 원인이 됩니다.
**Action:** 성능에 민감한 경로에서는 객체 할당을 방지하고 V8 엔진에서 파싱 속도를 크게 향상시킬 수 있도록 `Date.parse(string)`을 사용해야 합니다. 또한, 전체 리스트에 공통으로 사용되는 정적 계산(예: `sessionStartedAt`의 타임스탬프 계산)은 렌더링 루프 외부(`EventList` 컴포넌트의 `useMemo` 등)로 분리하고 숫자형 원시 값을 props로 전달해야 합니다.
